How it works — a small neural net per ticker predicting tomorrow's move

What this card is for: it is one input to the TradingAgents analysts and a standing check on whether this model has any edge — it only says BUY or SELL once it has beaten the naive baseline, and the paper account trades the TradingAgents rating shown beside it. For minute-by-minute calls use the Day trading tab.

Each ticker gets its own liquid time-constant network (a CfC cell, 32 units). Unlike a normal recurrent net, each neuron's "memory speed" changes with the input, so it can react quickly in volatile stretches and hold information longer in quiet ones.

Input: the last 10 trading days of 28 technical indicators (MACD, RSI, ATR, Bollinger bands, OBV, stochastics, Fibonacci levels, momentum…), expressed relative to price so a $50 and a $500 stock look alike. Output: tomorrow's return, shown as a predicted close.

Training: 5 years of daily prices; the oldest 80% trains the model, the newest 20% (~1 year) is held back to score it. Retrained once per ticker per day (~20s on the GPU), and each run feeds the forecast to the TradingAgents analysts as one input.

How much to trust it: every tile compares it against two dumb baselines on that held-back year — "tomorrow = today" (error) and "always up" (direction). Below baseline means it hasn't beaten them: treat it as a research signal, not a call. Next-day prices are close to a coin flip for any model.

How the calls work

There is no predictive model: the signal is each ticker's own move over the horizon window (Trade horizon, below). The knobs are the whole rulebook — a BUY NOW / SELL NOW fires when that move clears the entry bar (round-trip cost × Signal strength needed) and the stop / target / timing / alignment knobs allow it. Use a card's Buy / Sell buttons to trade by hand against the same knobs.

Replay past weeks with your settings to see how they would have done — the same signal and rulebook run over real past bars, then the week is scored. Prices tick every few seconds between bars.

Data: Yahoo 1-minute bars, which can lag the tape — the bar age is shown on every card.
